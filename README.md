# 🛡️ SecureAware

SecureAware is a security-awareness simulation platform designed to help organizations conduct controlled phishing-awareness exercises and understand how users respond to simulated suspicious emails.

The platform allows authorized administrators to create phishing-awareness campaigns, send simulated emails to authorized test recipients, track user interactions, and provide immediate security-awareness training based on the user's action.

> ⚠️ **Security Notice**
>
> SecureAware is intended strictly for authorized security-awareness and phishing-simulation activities.
> It must only be used with recipients and systems for which you have explicit authorization.
>
> SecureAware does not collect or process real passwords, OTPs, PINs, CVVs, card numbers, banking credentials, or other authentication secrets.

---

## ✨ Features

### 📧 Simulation Email Campaigns

- Create security-awareness email templates.
- Create and manage campaigns.
- Send simulated emails to authorized test recipients.
- Support realistic phishing-awareness scenarios.
- SMTP-based email delivery.

### 🎯 Authorized Recipients

- Add simulation recipients.
- Mark recipients as authorized test users.
- Prevent simulations from being sent to unauthorized recipients.
- Mask recipient email addresses in monitoring interfaces.

### 📊 Customer Activity Monitoring

Track how recipients interact with simulated emails:

- ✉️ Sent
- 👀 Opened
- 🔗 Link Clicked
- 🛡️ Reported as Phishing
- 🎓 Training Viewed
- ⏱️ Ignored

The Customer Activity Monitor provides:

- Real-time activity monitoring
- Simulation-level details
- Event timelines
- Security-awareness metrics
- Status-based activity tracking
